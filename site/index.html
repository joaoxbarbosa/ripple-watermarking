A watermark you can't see, that survives editing

Every fingerprinted token is an exact sample from the model's own distribution, so the text reads the same as normal sampling. The key holder gets an exact p-value for whether a model wrote it. This page shows one full run, misses included.

05Every reply

One fingerprinted and one plain reply per prompt. z is the standardized score: ordinary text sits near 0. The misses are replies where the model was close to deterministic, so there was little randomness to carry the signal.

06It survives editing

Each full reply is edited three times at random, then re-tokenized and checked at p < 10⁻⁵. An edit only spoils the four tokens around it, so the untouched runs still count. The curve starts at the unedited detection rate.

07No false alarms: the p-value is exact

08Which model wrote it?

Each model gets its own key from one master secret. Five models were registered on one tokenizer, and only model A sampled the replies. Under the wrong key the score is exactly that of ordinary text, so no other model can be blamed. The registry corrects for testing every model, so it needs a bit more evidence than a single-key check.

Mixed documents: plain reply + fingerprinted reply + plain reply

A span has to clear a correction for every possible stretch of text, so it needs a stronger reply than whole-text detection does.
