Ripple Fingerprint

An invisible signature that an AI model writes into its own text, so you can later prove which of your models wrote something.

Next: does it work? →Try it live ↗
01What is it?

A signature hidden in word choice

When the model picks each word, a secret key nudges which of its likely options it picks. Readers can't see it, and the text is exactly as good as without it.

02How do you check?

Run any text through the checker

The checker holds the secret key. It says whether one of your models wrote the text, which one, and how sure it is.

03Does it blame the wrong model?

No

It only says "this model wrote it" when the evidence is overwhelming. You choose the false-alarm rate, and the default is one in 100,000.

04What breaks it?

Rewriting the whole text

Fixing typos or changing some words is fine. A full paraphrase or translation erases it. Very predictable text, like code or short lists, carries only a weak signature.

06Good for
  • Checking whether a text came from one of your own models.
  • Telling your models apart, each with its own key.
  • Finding which part of a mixed document each model wrote.
07Not for
  • Spotting text from other companies' models. It only knows yours.
  • Proving a person wrote something. "Not found" only means no signature.
  • Models run with no randomness (temperature 0).
08Keep in mind
  • Longer is better. A few sentences may not be enough. A few paragraphs usually are.
  • Guard the key. Whoever holds it can check text, and also fake or remove the signature. Keep it on a server.
  • Not yet tested on Ripple-65B itself. The numbers here come from a 4B model on a laptop.
09Technical detailsmethod, settings, full numbers, code

Method

  • HMAC-SHA256(key, last 3 token ids) seeds a SHAKE-256 stream with one uniform u per vocabulary token.
  • The model picks argmax u1/p (exponential race). Each token is still drawn with probability exactly p.
  • The detector sums −log(1−u). For text the key didn't write this is Gamma(n, 1), so the p-value is exact.
  • Repeated 3-token contexts and the first 8 bits of surprisal use true randomness, so outputs stay diverse.
  • Per-model keys are HMAC(master, label). Attribution is corrected across all models and every span.
