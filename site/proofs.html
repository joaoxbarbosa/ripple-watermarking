Extraalgorithmic watermarking

Is the proof right, and who wrote it?

Lean, a proof checker, accepts a proof only if every step follows. The fingerprint names the model that wrote it. Fingerprinting never changes what a model can write, so a fingerprinted proof checks exactly like any other.
